Тестовое задание для AQA стажёра в компании учи

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

## Что было изменено в рамках тестового задания

### `tests/widget.page.ts`

- Исправлен селектор обёртки виджета: `WRAPPER` теперь соответствует реальному классу `widgetWrapper__`.
- Убран несуществующий селектор кнопки «Написать нам» (`[class^=btn]` был слишком общим и не находил нужный элемент).
- Добавлен селектор `BUTTON_ALL_ARTICLES` для кнопки «Смотреть все статьи».
- Селектор списка популярных статей уточнён — теперь он не захватывает закреплённую статью сверху.
- Добавлен метод `getOpenButton()` для проверки видимости кнопки открытия виджета.
- Добавлены методы `getArticleTitle()` и `getArticleText()` для проверки содержимого открытой статьи.
- Метод `getPopularArticles()` теперь дожидается появления первой статьи (до 10 секунд), чтобы избежать ложных падений из-за задержки загрузки.

### `tests/widget.spec.ts`

- Переписана логика теста проверки заголовка: теперь проверяется заголовок открытой статьи, а не заголовок в шапке виджета (он не меняется при навигации).
- Добавлен третий тест — проверка количества популярных статей (должно быть 5).
- В `beforeEach` принудительно устанавливается cookie `ab_mainpage_redesign = a`, так как виджет отображается только для этой группы A/B-теста.
- Добавлена защита от нестабильности: если кнопка виджета не появляется, тест помечается как `skipped` с пояснением. Это предотвращает ложные падения из-за внешних условий.

## Особенности

- **A/B-тест.** Виджет обратной связи на uchi.ru включён только для группы `ab_mainpage_redesign = a`. При значении `b` виджет скрыт. В тестах это значение фиксируется через `page.context().addCookies(...)`.
- **Нестабильность виджета.** Даже при правильной A/B-группе виджет может не отобразиться (например, из-за сетевых задержек или изменений на стороне сервера). В этом случае тест помечается как `skipped`, а не падает с ошибкой.
- **Загрузка статей.** Список популярных статей подгружается асинхронно. Метод `getPopularArticles()` ожидает появления первой статьи перед возвратом массива.
